# Ảnh minh họa sản phẩm demo

Ảnh tải ngày 15/10/2026, giữ nguyên nội dung gốc. Nguồn trang và URL ảnh nằm trong `sources.json`. Đây là ảnh sản phẩm tham khảo cho dữ liệu đồ án, không phải ảnh chứng minh tình trạng món đồ cũ của seller. Laptop demo dùng ảnh Dell Latitude 7480; tiêu đề seed chưa chỉ rõ model.

Các file được phục vụ từ `/assets/products/`. Khi chạy website, ảnh không cần gọi website bên ngoài.

Seed mới dùng các ảnh này. Migration `20261015010000_demo_product_images` chỉ thay URL `cdn.nola2hand.vn/demo/` của seller demo, giữ ảnh seller tự upload. Dữ liệu demo hiện có dùng origin local `http://localhost:4000`.
